# Product Requirements Document (PRD): OrderRestro

## 1. Product Overview
OrderRestro is a comprehensive restaurant management and Point of Sale (POS) system designed to centralize and streamline daily operations. 

## 2. Target Audience
* **Restaurant Managers/Owners:** For high-level oversight of revenue, waste, and staff.
* **Front-of-House Staff (Servers/Hosts):** For managing table statuses, taking orders, and handling reservations.
* **Back-of-House Staff (Kitchen):** For receiving and updating order statuses via the Kitchen Display System (KDS).

## 3. Key Modules and Navigation
The system includes the following core modules: [Dashboard](https://orderrestro-demo.nodedrdev.com/dashboard), [Point of Sale](https://orderrestro-demo.nodedrdev.com/pos), [Orders](https://orderrestro-demo.nodedrdev.com/orders), [Tables](https://orderrestro-demo.nodedrdev.com/tables), [Reservations](https://orderrestro-demo.nodedrdev.com/reservations), [Menu](https://orderrestro-demo.nodedrdev.com/menu), [Kitchen Display](https://orderrestro-demo.nodedrdev.com/kds), [Customers](https://orderrestro-demo.nodedrdev.com/customers), [Inventory](https://orderrestro-demo.nodedrdev.com/inventory), [My deliveries](https://orderrestro-demo.nodedrdev.com/my-deliveries), [Delivery](https://orderrestro-demo.nodedrdev.com/delivery), [Team](https://orderrestro-demo.nodedrdev.com/team), [Accounting](https://orderrestro-demo.nodedrdev.com/accounting), [Reports](https://orderrestro-demo.nodedrdev.com/reports), [Marketing](https://orderrestro-demo.nodedrdev.com/marketing), [Operations](https://orderrestro-demo.nodedrdev.com/operations), [Attendance](https://orderrestro-demo.nodedrdev.com/attendance), and [Settings](https://orderrestro-demo.nodedrdev.com/settings).

## 4. Feature Requirements

### 4.1. Dashboard & Analytics
* **Real-Time Metrics:** Must display live data for today's revenue, total orders, occupied tables, pending payments, active customers, and team members.
* **Financial Tracking:** Must include visual charts tracking revenue over a 14-day rolling period.
* **Operational Tracking:** Must include visual charts monitoring food waste costs over a 14-day rolling period.
* **Alerts & Notifications:** Must provide dashboard indicators for low stock items and pending payroll to pay.

### 4.2. Order Management & Point of Sale (POS)
* **Order Creation:** Quick access to create [New order](https://orderrestro-demo.nodedrdev.com/pos) directly from the dashboard.
* **Omnichannel Support:** Must track and differentiate orders from multiple channels:
    * *Self-serve:* [Online (QR / kiosk)](https://orderrestro-demo.nodedrdev.com/orders?tab=history&filter=online).
    * *Staff-entered:* [Offline (dine-in / takeaway / phone)](https://orderrestro-demo.nodedrdev.com/orders?tab=history&filter=offline).
* **Transaction Logging:** Must keep a running list of recent transactions including order ID, type (DINE IN, TAKEAWAY, DELIVERY), and total monetary amount.

### 4.3. Table & Reservation Management
* **Real-time Table Status:** Monitor table states categorized strictly by: Available, Occupied, Reserved, and Cleaning.
* **Reservations:** Functionality to log a [New reservation](https://orderrestro-demo.nodedrdev.com/reservations) directly from the main view.

### 4.4. Kitchen Display System (KDS)
* **Queue Management:** Digital display for the kitchen to track order progression and the total number of items in the queue.
* **Status Workflows:** Categorize tickets into actionable stages: New, Accepted, Preparing, and Ready.

### 4.5. Additional Functionality
* **Localization:** The platform must support multiple languages, including an English (EN) toggle.
* **Role-Based Features:** Accommodate different user profiles (e.g., Demo Visitor) and allow customization of the dashboard layout.
